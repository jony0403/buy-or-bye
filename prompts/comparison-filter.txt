역할:
우리가 보고 있는 중고 매물과 검색으로 수집한 후보 매물이 같은 제품인지 판별하세요.

목표:
구매 판단용 가격 참고자료로 쓸 수 있는 후보만 남기는 것입니다. 이 결과를 보장된 시세로 단정하지 않습니다.

입력:
기준 매물:
제품명: {{productName}}
제목: {{title}}
본문: {{body}}
제품 요약(JSON): {{summaryJson}}

후보 매물(JSON):
{{candidatesJson}}

처리 기준 (반드시 지키세요):
- 같은 브랜드 + 같은 제품 라인 + 같은 세대/모델이면 match에 넣으세요.
- 한글/영문 표기는 같은 것으로 보세요. 예: 아이폰=iPhone, 갤럭시=Galaxy, 기가=GB, 에어팟=AirPods, 맥북=MacBook.
- 용량(128/256/512GB, 1TB 등)이 기준 매물에 있으면 같은 용량만 포함하세요. 용량이 다르면 제외하세요.
- 색상·구성품·박스 유무만 다르고 핵심 모델·용량이 같으면 포함하세요.
- 다른 세대/다른 모델/케이스·충전기·필름·부품·호환품·주변기기만 파는 글은 제외하세요.
- 제목에 모델명이 약해도, 제품명·요약과 핵심 토큰이 겹치면 포함하세요.
- 확신이 애매해도 핵심 모델·용량이 맞으면 포함하세요. (너무 보수적으로 전부 빼지 마세요.)
- 가격이 이상하다는 이유만으로 제외하지 마세요. 제품 동일성만 판단하세요.

출력 형식:
반드시 JSON만 출력하세요:

출력 스키마:
{
  "matches": [
    { "key": "후보 key", "same": true, "reason": "같은 제품으로 본 짧은 근거" }
  ],
  "rejected": [
    { "key": "후보 key", "reason": "제외한 짧은 이유" }
  ]
}
